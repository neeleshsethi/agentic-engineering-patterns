Asking back is a control-flow event

Clarifications are not chat garnish. They decide whether a plan exists, whether a report is allowed, which source gets retried, and which evidence is carried forward.

Source elicitation

Detection is deterministic and shared

CortexThe source marks a text item with is_elicitation: true. Deep trusts the flag.
IQVIA/GMIA deterministic outcome ladder checks errors, failed state, native input-required, explicit markers, question-shaped no-table replies, and no-data phrases in order.

The legacy quick graph had an LLM-based classifier. The reactive and deep paths do not depend on that classifier.

Acting on the flag

Reactive trusts the prompt. Deep adds a code backstop.

ModeWhat stops the answerBookkeeping
ReactivePrompt rules tell the one-pass router to relay the source question.Results stay in state; the next turn reuses carried data.
DeepThe prompt relays, and exit middleware skips report generation if pending_elicitation() is true.The step stays open; only that step is re-queried after the user answers.

Partial clarification

One source asks back, the whole report waits

1
Two sources run. IQVIA returns data. Cortex asks for retail versus non-retail.
2
The report is blocked. pending_elicitation checks each step's latest successful result, so deep does not ship a partial report.
3
Data is not lost. The IQVIA result remains in accumulating source_results.
4
The reply re-queries only Cortex. The user's answer is folded into the open step's sub-question.

Resume or new turn?

Mid-retrieval elicitation is not Command(resume=...)

Plan approvalLeaves a pending interrupt(). Approval enters through the approve endpoint, SQS, worker, and graph resume.
Elicitation replyThe elicitation turn completed normally. The user's answer is a fresh graph invocation on the same thread_id.

It does not re-plan. The plan remains locked, the cycle remains the same, and carried evidence stays attached.

LangChain runs after_agent hooks in reverse registration order, so the sufficiency gate runs before the report writer.

Budgets

Meter depth, not breadth

Retrieval roundsDefault 6. A model turn with one or many retrieval calls counts as one round.
Recursion limitDefault 50. This is a backstop, not the primary loop control.
SQS receivesAttempt 3 is poison-pill territory: fail, delete, and stop retrying.

Parallel fan-out is free because it reduces wall-clock time without making the reasoning loop deeper.
